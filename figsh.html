Ekuyik Sam

Figsh · Full-Stack Developer & Creator of FSCSS

Akwa Ibom, Nigeria · Last reviewed: 14 Nov 2026

Identity overview

Ekuyik Sam, publicly known as Figsh, is a self-taught full-stack developer from Akwa Ibom, Nigeria. He designs and builds lightweight frameworks, pure-CSS systems, APIs and open-source packages with a focus on modularity and minimal runtime cost.

He is the creator of FSCSS (Figured Shorthand Cascading Style Sheets), a CSS preprocessor that compiles shorthand syntax, variables, arrays, pattern matching and modules into plain, dependency-free CSS. The project is maintained under the fscss-ttr organization and published as the fscss package on npm.

Primary source: figsh.devtem.org · Project docs: fscss.devtem.org

Background

Figsh describes an early path from physical experimentation (toys and circuits) into software. FSCSS grew out of experiments with regular expressions and “functions” in stylesheets, released initially without a formal product plan. Documentation places conception around 2022, with progressive public releases through 2025–2026 (npm publication, browser runtime, array methods, pattern matching, and the 1.2.x entry-point consolidation).

Background narrative: figsh.devtem.org · History notes: FSCSS docs / Project Background

Projects & contributions

FSCSS / xfscss

Lightweight CSS preprocessor with property shorthands, variables, style stores, arrays and methods, pattern() semantic matching, remote modules and browser runtime. Compiles to standard CSS. Core engine of the ecosystem; maintained by Figsh with the fscss-ttr organization.

Docs GitHub (compiler) Modules org npm

st-core.fscss

Pure CSS statistical charts and dashboard design system built for FSCSS. Dynamic arrays, clip-path polygons, zero JavaScript runtime for core visualization.

GitHub

ProvChart

Animated multi-line charts driven by CSS custom properties. No chart library and no JavaScript runtime for rendering.

Site

devtemDesign

Zero-dependency page engine: one configuration object produces animated landing pages (templates, theme switching, sections). Plain HTML, CSS and JS.
